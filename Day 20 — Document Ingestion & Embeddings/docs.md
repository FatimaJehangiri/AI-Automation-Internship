# Petalnex — Product Documentation

## Supported Vector Databases
Our platform supports Supabase Vector, Qdrant, and Pinecone as vector store backends. All three offer generous free tiers for prototyping.

## How Chunking Works
Long documents are split into overlapping chunks before embedding so that each chunk fits the model context window and preserves surrounding context.

## Integrations Available
Petalnex integrates with Slack, Gmail, Google Sheets, Notion, and hundreds of other apps through the n8n automation platform.
