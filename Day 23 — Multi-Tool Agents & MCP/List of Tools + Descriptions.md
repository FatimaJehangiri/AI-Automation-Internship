# Day 23 — Multi-Tool Agent & MCP

## List of Tools + Descriptions

| # | Tool Name | Type | Description |
|---|-----------|------|-------------|
| 1 | Public Weather HTTP Tool | HTTP API | Fetches current weather data using Open-Meteo API. Requires latitude and longitude parameters. Read-only. |
| 2 | Calculator | Arithmetic | Performs mathematical operations including addition, subtraction, multiplication, division, and exponentiation. |
| 3 | Google Sheets Data Store | Database | Reads employee records from a Google Sheet. Searches and retrieves row data based on queries. Read-only. |

| 5 | Sensitive Demo Write | HTTP API | Creates demo records via POST requests. Never autonomous - requires human approval before execution. |
